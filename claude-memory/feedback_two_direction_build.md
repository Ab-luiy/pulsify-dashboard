Founder 2026-10-12 (long voice brief after Phase 1 screenshots):

- **Two directions, always.** Build the frontend AND write down exactly how the backend must be wired for it (endpoints, data, which vault frameworks/JSON profiles feed the generator, what fires what), in the backend notes doc, so a later session never rescans from zero. Notes live in pulsify-saas `docs/backend-wiring.md`.
- **Client portal first.** Operator-side ideas go in the same notes as "operator: later".
- **I am the only engineer** until there's revenue. Do the work; never tell him to do it. Make it runnable and playable; someone is testing the app now.
- **Creation is question-led.** "You want to make X. What's it about? What do you have? Here are examples." Help the thought process, don't force structure. No internal method names shown (Methodology/Taxonomy/Philosophy were "cringe"; nobody calls them that).
- **Carousels:** AI generates them from the client's photos and data after a few questions; the manual slide editor is too limited to be the main path.
- **Look:** minimalistic, professional, dynamic (charts, sliders, visual data, animation). No blocks crammed with small text and examples. Hover "i" tooltips plus a help/wiki for explanations. Better icons. Section bars fully black, not grey. Blue glow "depressing", replace it. Pulsify logo on the island bigger. Loading = glowing logo in the middle. Real 404. Everything linked. No overlap when the window resizes.
- **Integrations:** clients connect their own Instagram and YouTube by signing in. He never connects anyone's accounts.
- **IG and YouTube sections** each need a content pipeline and calendar with visual data.
- **Onboarding:** remove repeated questions.
- **Power up:** generation runs server-side on our key, using the vault's frameworks (story sequences, carousels, context profiles) without exposing them.
- Reference he trusts on SaaS: Luke Alexander (made $1M year one). Revenue is the point; ship the MVP, then outreach.

**Why:** Phase 1 screenshots still read as "a lot of noise that doesn't do any work". **How to apply:** this overrides the slower phase plan in [[project_frontend_overhaul_2026_10_12]]; also follow [[feedback_dashboard_quality_bar]], [[feedback_app_wording]], [[feedback_one_stack]].
