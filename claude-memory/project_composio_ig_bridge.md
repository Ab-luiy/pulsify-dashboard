- **Pull tool:** `awesome-bassi-d88340/ig-report/` — `npm start` pulls profile (`INSTAGRAM_GET_USER_INFO`), account insights (`INSTAGRAM_GET_USER_INSIGHTS`), audience demographics (`follower_demographics` breakdowns), and reels+insights → Hook Score (`render.ts`). - **Dashboard tab:** new `data-tab="instagram"` tab in `index.html` with `renderInstagram()` reading `D.instagram`. Cards: Profile & Growth, Content performance (Hook leaderboard), Audience (countries + age donut), Instagram funnel (content→revenue, bottom from CRM `source=instagram`), Repurpose-vs-YouTube. Embedded `<script id="data">` has `instagram` zero-defaults for file:// / pre-pull.
- **Gotchas learned:** account-level daily `USER_INSIGHTS` are near-zero/sparse for small accounts (only last ~2 days) → Growth is driven by reel-derived totals, account series flagged `available:false`. `profile_views`/`website_clicks`/`impressions` are deprecated (Graph v21) — use `reach`/`views`/`profile_links_taps`. Insights `metric` param is an array; `INSTAGRAM_GET_IG_USER_MEDIA` needs `ig_user_id:"me"` + explicit `fields`; media response is double-wrapped (`data.data`). The shared `sparkline()` is scoped inside `renderDashboard` — top-level helpers (`renderInstagram`) need their own (`igSpark`).

**Splits + auto-refresh (2026-06-14):** the IG tab is split into **Reels / Posts / Stories** bands, each with format-appropriate metrics + a prescriptive **Action Engine** line grounded in Pulsify brain standards (1 reel/day, daily stories, carousel grid as profile-funnel landing page, bio trigger word). The pull (`agent.ts`) splits media by `media_product_type` (REELS vs FEED) and captures **stories** via `INSTAGRAM_GET_IG_USER_STORIES` (only returns ACTIVE ≤24h stories → `accumulateStories()` merges by id so history is never lost). Story metrics available: reach, replies, navigation, profile_visits, follows — **NOT total watch time** (reels-only metric; use completion/navigation instead). Daily auto-refresh via `.github/workflows/refresh-ig-analytics.yml` (cron 05:00 UTC → `npm start` in ig-report → commit `dashboard-data-v2.json` → push to main → redeploy). **Requires `COMPOSIO_API_KEY` as a GitHub repo secret to function.** Brain standards mined from `wiki/content-engine/content-pillars.md` + `wiki/concepts/profile-funnel.md`. ⚠ **These standards are LONG-FORM/YouTube-derived and applied to IG provisionally** — founder flagged (2026-06-14) that validated SHORT-FORM IG strategy doesn't exist yet, so the IG Action Engine must NOT assert heavy claims until the short-form playbook is built ([[project_shortform_ig]], [[feedback_flag_gaps_no_heavy_claims]]). Offer to soften them to neutral observations.
