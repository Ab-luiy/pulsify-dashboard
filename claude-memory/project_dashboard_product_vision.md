As of 2026-06-14, the Pulsify dashboard is **not just the founder's internal tool — it's a productized system we sell to coaches/consultants** (the same dashboard + backend installed for each client). It's the proof-and-tracking layer that justifies Pulsify's **$10K setup fee**.

**The $10K promise (per founder):** there's no formal "what we show" doc — the commitment is *"we take their business A-to-Z to a specific promised revenue number, doing everything (marketing, backend, tracking) to get them there."* So the dashboard must be a **picture-perfect, prescriptive** view that ladders every metric up to "are we on track to that number, and what's blocking it."

**The product bar (what makes it worth $10K):** a metrics screen is worth $0; a dashboard that says **what's broken + the one move to fix it** is the product. Build a prescriptive **Action Engine** into every section (started on the IG tab — cadence/hook/profile-funnel callouts driven by [[project_composio_ig_bridge]] brain standards). Ideas in flight: a single **Growth Grade (A–F)**, **benchmarks** (derive from the Pulsify brain / Obsidian, not generic "typical coach" numbers), **content→cash attribution**, **"what to post next"** from top Hook Scores + comment questions, and a **weekly auto-digest**.

**Productization (future workstream, not built):** today the dashboard is single-account (hardcoded to the founder's IG). Selling to coaches needs **multi-client**: each client = their own Composio connection (separate `userId`/connected account) + their own data file + their own view (client selector or per-client deploy). Founder to line up a first real coach to build + prove the multi-tenant flow against. Ties to [[project_hta_dashboard]] (client-facing CRM pillar) and [[feedback_dashboard_quality_bar]] (million-dollar-grade; take time over cringe-but-fast).

**Division of labor stays:** founder runs outreach; I run analytics + weekly lead gen/enrichment + the dashboard build. See [[project_composio_ig_bridge]].
