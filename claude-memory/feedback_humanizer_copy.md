The user supplied a "Humanizer" SOP (full file: `C:\Users\Abdullah\Downloads\Humanizer AI Prompt.md`) after flagging that dashboard copy "reads AI generated." Treat it as the writing standard for ALL copy I produce: dashboard/portal text, affirmations, plan copy, content-gap notes, deliverables, and ideally chat replies too.

Top tells to avoid (condensed):
- Negative parallelism: "It's not X, it's Y" / "X, not Y" / "The question isn't X, it's Y". Also "Not X. Not Y. Just Z."
- Self-posed rhetorical question then answer: "The result? Devastating."
- Em-dash overuse (a human uses 2-3 a piece, not 20). Prefer commas, periods, parentheses.
- Bold-first bullets (every list item starting with a bold keyword) — a Claude/ChatGPT tell.
- Tricolon / rule-of-three padding; anaphora (repeating the same sentence opener).
- Filler transitions: "it's worth noting", "notably", "importantly", "interestingly".
- Hype openers: "Here's the thing/kicker", "Here's where it gets interesting", "Let's break this down / unpack / dive in", "Think of it as", "Imagine a world where".
- "Serves as / stands as / represents / marks" instead of plain "is".
- Overused vocab: delve, leverage (verb), robust, streamline, utilize, harness, tapestry, landscape, paradigm, synergy, ecosystem.
- "-ing" tail analysis: "highlighting its importance", "reflecting broader trends".
- False ranges: "from X to Y" when there's no real spectrum between.
- Invented concept labels: "the supervision paradox", "the acceleration trap".
- Grandiose stakes inflation; vague attributions ("experts say", "industry reports").
- Unicode decoration: curly quotes and arrows (→). Use straight quotes and plain text.
- Short fragment paragraphs for fake emphasis; fractal summaries; beating one metaphor to death.

**Why:** placeholder/affirmation/content copy I'd written read as generic AI; the user wants on-brand, human copy in their real voice (pull voice from the brain), not slop.
**How to apply:** write plainly and specifically; vary sentence structure; straight quotes; minimal em-dashes; no bold-lead bullets; name real sources; cut filler.
