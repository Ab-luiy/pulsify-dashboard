The VSL is NOT killed. Two funnels exist and must stay distinct in the vault:

1. **Founder's personal go-to-market funnel** (Pulsify selling Pulsify): YouTube → IG profile → DM → call. No VSL. Founder is a creator selling B2C-style to coaches who self-qualify by watching long-form. A VSL here would be friction.
2. **The Funnel Stack Pulsify installs for clients** (Pulse System component #3): still includes VSL, Typeform, Cal.com. Client audience is high-ticket consumers where the VSL is load-bearing.

**Why:** On 2026-05-15 I proposed updating the funnel doc to "reflect the VSL kill" — founder corrected: he's removing the VSL from his *personal* funnel only, not from the Pulse System deliverable. Conflating the two would have erased a client-facing deliverable from the offer.

**How to apply:** When editing funnel/offer/Pulse-System docs, always check which funnel is being modified. Founder funnel changes should not propagate to client-deliverable Funnel Stack changes and vice versa. Default to asking if unclear.
