# VSL transcript intake

This folder stores raw VSL transcripts supplied by Abdul.

Rules:

- One VSL transcript per file.
- Do not rewrite the transcript in place.
- Do not use a transcript as a swipe file.
- Use transcripts to extract structure, persuasion mechanics, belief shifts, proof patterns, and offer logic.
- Analysis belongs in `wiki/synthesis/vsl-patterns/`.

Recommended filename:

`{operator-or-offer-name}-vsl-transcript.md`

Recommended frontmatter:

```markdown
---
source_type: vsl-transcript
offer:
market:
speaker:
url:
transcribed_by: Abdul
transcribed: YYYY-MM-DD
notes:
---
```
