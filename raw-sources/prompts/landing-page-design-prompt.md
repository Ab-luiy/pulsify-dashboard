# Landing page design prompt

Build a high-converting landing page for a [niche] high-ticket mentorship targeting [audience size and ICP]. Model the layout after [competitor or top-of-niche page URL] but make it unique, clean, and modern. This is the main conversion funnel: the viewer already knows the creator, lands here, watches a VSL, fills out a qualifier, books a call. This pass is structure and design only. Use placeholder copy throughout, real copy comes separately, so focus everything on layout, hierarchy, and feel.

## Structure, top to bottom

1. Hero: bold headline slot + subhead slot, with one primary CTA button above the fold. No clutter competing with it.
2. VSL slot: a clean 16:9 video player with a play button, centered, no autoplay. This is the visual anchor of the page.
3. Qualifying application form directly under the VSL. Fields: First Name, Email, Instagram (optional), Phone, Age, Current Situation, 3 Month Target, Why now. Style it like a serious application, not a newsletter signup, so unqualified leads self select out.
4. A clear "Book Your Call" CTA that the form leads into.
5. Testimonial wall: a grid of real proof presented as screenshot tiles and short video tiles, not retyped quote graphics that look fake.
6. Short closing CTA section that restates the next step.

## Length, match the page to the audience

- Large audience: full long form, more social proof, more form fields.
- Mid size (around 10k): leaner, shorter VSL slot, tighter sections.
- Micro niche: strip it down to headline plus VSL plus booking link, the viewer is basically pre sold.

## Design

- Mobile first. Headline, video, and form all have to work on a narrow screen first.
- Raw and authentic over flashy. Absolutely no lifestyle flexing anywhere: no cars, watches, money fans, private jets. Trust over decoration.
- Clean and modern. Generous spacing, strong type hierarchy, one clear action per screen. Lean minimal for a serious or affluent buyer, slightly more visual structure for a broad audience, but never hype scam energy.
- Make it look genuinely custom, not a template. Distinct layout, intentional sections.

## Deliverable

Build the full responsive page on the canvas with placeholder copy and placeholder proof tiles in place. After the first version, give me 2 or 3 specific layout or hierarchy tweaks you would test to lift conversions.
