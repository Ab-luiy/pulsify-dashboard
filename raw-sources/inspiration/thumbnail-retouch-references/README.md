# Thumbnail retouch references

Founder-supplied examples of Codex image retouches he approved. These define the target for the soft-retouch thumbnail workflow: the person is untouched, the image is simply cleaner and the subject reads better.

## What goes in here

Before and after pairs where possible. Name them so the pair is obvious:

- `01-before.png` / `01-after.png`
- `02-before.png` / `02-after.png`

If only the after exists, `03-after.png` on its own is fine.

## What these are for

Reference only. They show the degree and kind of retouch, not the content. Do not generate images that copy the founder's own likeness, room, or composition from these. The transferable part is the treatment: how far the retouch goes and where it stops.
