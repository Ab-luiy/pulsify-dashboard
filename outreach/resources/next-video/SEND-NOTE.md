# Next-video resource

Reusable general content resource. No prospect-specific editing is needed. Built at the founder's request on 2026-09-12; effectiveness is untested.

## Send

Default placement: day 2 after the opener, following a brief day-1 reminder. Attach `next-video.png` directly in the DM with this exact founder-approved line:

> figured this might come in handy on those days where you know your stuff but can't decide what to make a video about

If the recipient requests material before day 2, send it then and stop the automatic unanswered sequence. Do not resend the same resource on day 2. The PDF is optional when they want a document; the PNG is the default attachment.

This is a general resource, not a personalized audit. For a lead already promised a personal audit, introduce this as an additional resource and keep the original promise separate.

## Content and production

Five prompts draw on the recipient's actual questions, decisions, mistakes, changed beliefs and process. Each includes an opening starter. No invented results, trading advice, sales CTA, mentorship reference or client-specific assumptions.

The approved conversation supplies the five-direction concept and send line. Existing context: wiki/content-engine/content-pillars.md and claude-memory/feedback_content_targets_b2c_coaches.md. This is content support for creators; the examples they make remain about their craft.

Build with `build.py` using ReportLab. Render the one-page PDF with Poppler at 144 dpi to produce a 1080 x 1600 PNG. Canonical files live beside this note. User-facing copies are in the originating Codex task's outputs folder.
