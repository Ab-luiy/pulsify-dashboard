# Lead intel

Persistent per-lead memory for outreach work.

This folder exists so a prospect does not live only in chat history, Perplexity, or one-off notes. Every time a lead matters, make a file here and keep it current.

## What goes here

- The creator profile / notes that came in
- The main leak we diagnosed
- The one personal detail we are using in copy
- Every asset we built
- Every message we drafted or sent
- The last action taken
- The recommended next action

## Rule

If we touched the lead in a meaningful way, update the lead file before ending the session.

Meaningful work includes:

- profile/brief ingested
- landing-page angle decided
- landing page built
- DM drafted
- email drafted
- Typeform drafted
- VSL angle decided or script drafted
- offer/funnel audit drafted
- follow-up copy drafted
- message sent
- reply received

## File naming

Use the creator's name or handle in kebab-case.

## Source of truth fields

Every file should answer these fast:

1. Who is this lead?
2. What is the core leak?
3. What personal detail are we leaning on?
4. What have we already built?
5. What was the last thing we did?
6. What should we do next?

## Copy rule

When the founder wants stronger outbound copy, Codex does not stop at the first decent draft. Use Claude for the final copy pass and save the improved DM/email back into the lead file so the better version becomes reusable.
