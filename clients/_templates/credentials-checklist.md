# Credentials checklist template

Goes to the client with the welcome email. Due by Day 3. Per [[wiki/playbooks/pulsify-delivery-sop]]: any missing item escalates same-day; refusal of payment-processor access voids the engagement per the offer terms — that conversation happens on the game-plan call, not over email.

---

## What we need by [Day 3 date]

Work down the list; reply in [Slack channel] as each lands. "Done" beats "will do."

**Instagram**
- [ ] Admin or scheduling access via Meta Business Suite ([your IG handle] added as partner, or login via password manager share)

**YouTube**
- [ ] Channel access via YouTube Studio permissions (Editor role minimum) to [email]

**Email provider**
- [ ] Login or team seat on [their ESP — fill after game-plan call]

**CRM**
- [ ] Access to existing CRM, or confirm none exists (we set up a Notion board in that case)

**Payment processor**
- [ ] Read access to Stripe / bank export view / [their processor]. This is the source of truth for the $100k tracker — non-negotiable, and it protects both sides because we read the same number.

**Calendar / booking**
- [ ] Cal.com / Calendly admin or team access

**Content archive**
- [ ] Folder of past videos, thumbnails, and any scripts (Drive link is fine)
- [ ] Exports of any past sales call recordings you have

**Passwords**
- [ ] Shared via [password manager / agreed method] — never in plain Slack messages

## Why each of these

Every item maps to a build week: IG and YouTube feed the Week 2 profile renovation, the content archive feeds the Brand Brain, the processor view feeds attribution, the calendar feeds the Sales Co-pilot. Missing access doesn't pause the clock on the 90 days, so Day 3 matters.
