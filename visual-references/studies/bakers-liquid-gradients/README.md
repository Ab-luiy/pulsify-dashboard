# Bakers Studio liquid gradient study

Source: https://x.com/studiobakers/status/2102349193881006288
Reviewed 2026-09-29 at the founder's request.

Three source videos, each 11.167 seconds, 2160 x 3052, 60 fps. Sampled all three at 0/2/4/6/8/10 seconds and inspected an enlarged frame for texture. This is a frame-based motion analysis, not recovery of the original project or shader.

## Deliverables

- visual-profile.json: reusable source observations, per-clip evidence, measured approximate palettes, reproduction prompts, and a separately marked proposed Graphite adaptation.
- media-metadata.json and palette-measurements.json: measurements and method notes.
- source-*-timeline.jpg: six timestamped frames per clip.
- source-*-04s.jpg: full-size texture references.
- source-*.mp4: original source clips for reference analysis.
- Python scripts: reproducible frame extraction, palette measurements and profile construction.

## What makes the reference work

A few large ribbons bend, pinch and widen; lighter seams run between broad color fields. Motion changes the shape of the color boundaries. Fine grain adds texture without becoming the subject. The source has mint/aqua, blue/yellow and coral/cream variants. These bright palettes do not supersede the founder's chosen Graphite base.

For Pulsify: reproduce that soft deformation and grain in graphite and silver, confined to the background surrounding the solid central panel. Keep the fixed sidebar and all internal dashboard gaps opaque. Optional glass controls are a separate design decision; these videos demonstrate gradients, not glass.

The original tool, shader and easing are unknown. Proposed shader parameters in the JSON are starting points to test. Seamless looping is not established. Source logos/copy remain reference material and are not part of the regeneration prompts.
