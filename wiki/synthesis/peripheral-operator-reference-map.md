# Peripheral operator reference map

This page keeps secondary operators useful without letting them distort Pulsify's strategy. These people are reference points, not anchors.

## Why this matters for Pulsify

More inputs can make the vault dumber if every input gets equal weight. Pulsify needs a strong center: content -> offer -> funnel. Secondary operators are only useful when they sharpen a specific layer.

## Reference map

### Cole Gordon

Use for sales infrastructure.

Useful patterns:

- internal sales department positioning
- setter and closer roles
- repeatable sales process
- sales team recruiting and ramp-up
- call analysis and objection handling

Boundary:

- Do not let sales-team mechanics become the main Pulsify promise before the client's content and offer are fixed.

### Ayman Arab

Use for YouTube sales funnels.

Useful patterns:

- YouTube as a sales engine, not content theater
- content operating system
- pre-sold calls from long-form content
- dynamic pre-call flows
- measuring booked calls per video instead of views

Boundary:

- Do not copy TikScale's agency promise directly. Pulsify's content engine is tied to offer and funnel infrastructure.

### Grayson Loupas

Use for social funnel contrast.

Useful patterns:

- simple content-to-DM-to-call path
- paid social attention
- daily content and story nurture
- coach-specific social proof loop

Boundary:

- This is a contrast to full VSL funnels, not Pulsify's whole model.

### Dan Bolton

Use for simple organic authority and funnel economics.

Useful patterns:

- low-complexity offer stack
- no-call funnel contrast
- lifestyle-light authority
- simple breakdown content

Boundary:

- Do not import "no sales calls" as a default. Pulsify sells high-ticket infrastructure where calls remain central for most clients.

### Joel Kaplan

Use for ethical operator framing.

Useful patterns:

- free YouTube education as trust builder
- paid coaching/implementation as the monetization layer
- "real operator" contrast against low-integrity coaches
- case study library

Boundary:

- Do not copy broad agency education positioning.

### Abdoulaye Waly

Use for current market language.

Useful patterns:

- coaches and agencies grouped under high-ticket scaling
- acquisition, sales, fulfillment, dashboards, and content engine language
- 16-week plan / blueprint framing

Boundary:

- Treat as language scan only. Do not use as strategic authority.

### Sam Ovens

Use for legacy consulting VSL structure.

Useful patterns:

- problem-first consulting logic
- niche and offer clarity
- mechanism and implementation program framing
- webinar/VSL education-to-sale structure

Boundary:

- Sam-era Consulting.com is historical. Do not use it as current market proof.

## How Pulsify uses this

When writing a new VSL, landing page, or outbound angle:

- Pull sales-team pieces from Cole only if the client has enough call volume.
- Pull YouTube measurement from Ayman when building inbound systems.
- Pull social funnel contrast from Grayson when a simpler profile funnel is better than a VSL.
- Pull simplicity from Dan when the offer is overcomplicated.
- Pull ethical operator framing from Joel when fighting market distrust.
- Pull current market wording from Abdoulaye when scanning how offers are being packaged now.
- Pull Sam only when studying classic VSL flow.

## Open questions / gaps

- None of these secondary sources should get a full wiki person page unless Pulsify starts using them repeatedly.
- Their actual VSL transcripts should be captured only if there is a clear reason.
