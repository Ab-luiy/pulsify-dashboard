# Jeremy Haynes Inner Circle page analysis

Jeremy's Inner Circle page is a minimal high-ticket application page with an embedded Wistia VSL, name/email gate, testimonial path, scarcity, and unusually strong disclaimers. It matters for Pulsify because it shows that a high-ticket page can be sparse if the status, video, application path, and legal posture are doing the work.

## Page map

| Element | What happens | Function |
|---|---|---|
| Event anchor | Shows a mastermind date and location. | Creates immediacy and real-world status. |
| Headline | High-ticket product or service scaling. | Defines broad buyer category. |
| Embedded video | Wistia VSL appears twice in the page. | Main persuasion asset. Transcript not captured. |
| Email gate | Name and email are required before application page access. | Turns curiosity into intent and captures lead. |
| Scarcity | Limited member count and mastermind timing. | Creates constraint, though the page shows stale/inconsistent details. |
| Disclaimer | Strong anti-income-claim language. | Reduces legal and psychological overpromise risk. |
| Testimonials path | Separate member testimonial link. | Keeps proof available without crowding the main page. |

## What Pulsify can adapt

- Minimal page confidence. The page does not need to explain every deliverable before the next step.
- Email gate before application when the buyer has enough status and intent.
- Separate testimonial path instead of stuffing all proof above the fold.
- Strong disclaimers that make the offer feel more serious, not less serious.
- The CTA should be framed as an application, not a casual chat.

## What Pulsify should not copy

- Do not copy stale event dates or inconsistent scarcity.
- Do not use income-result language before proof is strong.
- Do not use mastermind positioning unless Pulsify is actually selling a mastermind.
- Do not claim the embedded VSL has been analyzed until a transcript is captured.

## Cold outreach implication

For personalized VSLs, the landing surface can stay simple:

- prospect-specific headline
- short diagnostic VSL
- one visual map
- one CTA
- short proof/disclaimer

The page should not become a bloated proposal. The personalized VSL earns the next step.
