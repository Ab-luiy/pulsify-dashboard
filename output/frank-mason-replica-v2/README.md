# Frank Wieler — Mason-inspired prospect page

Static landing-page prototype rebuilt from the Manus export.

## Files

- `index.html` — landing page
- `css/style.css` — responsive design
- `js/script.js` — VSL placeholder and Typeform-style application
- `assets/frank-product-video.jpg` — Frank's public YouTube thumbnail used as the training preview

## Run locally

```powershell
python -m http.server 8765
```

Open `http://localhost:8765/output/frank-mason-replica-v2/` when serving from the
repository root.

## Before launch

1. Replace the training preview with Frank's recorded VSL.
2. Replace the prototype application with the final Typeform and calendar flow.
3. Add only verified student screenshots, dashboards, and raw video clips.
4. Verify every public result claim with Frank.

The page deliberately avoids invented testimonials or proof.
