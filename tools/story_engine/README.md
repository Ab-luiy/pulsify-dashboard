# Story engine

Reusable slide types for Instagram story sequences. A sequence is data (a spec JSON) plus a brand (tokens JSON). Change the brand and every slide restyles. Built 2026-10-09 from the Pulsify SaaS highlight as layer 2 of generalizing it; the process and question bank are in `wiki/playbooks/story-sequence-client-flow.md`.

```
python build.py examples/pulsify-designed.json ../../output/story-engine-samples/pulsify-designed
python build.py examples/simple-take.json      ../../output/story-engine-samples/simple-take
python build.py examples/pulsify-designed.json ../../output/story-engine-samples/designed-blue brands/sample-client-blue.json
```

Output: `01.png ...` at 1080x1920 and `sheet.jpg` (contact sheet). The third command restyles the same copy with another brand.

## Copy gate

`build.py` refuses to render unless the spec has `"copy_status": "approved"`. Copy is approved with the client first, then design. `--draft` previews anyway.

## Spec

```json
{"brand": "../brands/pulsify.json", "tier": "simple|standard|designed", "copy_status": "approved",
 "slides": [{"type": "type_stack", "lines": ["every creator", "had the *skill.*"],
             "photo": {"src": "photos/cafe.png", "mode": "fresh", "focus": [0.5, 0.5]}}]}
```

Copy markup: `*word*` emphasis (underline, or accent color if the brand turns underlines off), `[word]` marker box with an accent word (accent color if boxes are off), `{word}` gradient label (solid accent if gradients are off).

Photo reuse: put the same `src` on consecutive slides and set `"mode": "carry"` on the repeat. Carry is a blurred, dimmed cover crop. Crops are natural cover crops, never mirrored or stretched.

## Slide types

| Type | Tier | Fields |
| --- | --- | --- |
| `type_stack` / `closing` | simple | `lines`, optional `sub`, `icons`, `pos` (top, center, bottom), `center`, `size` |
| `pills` | simple | `lines` (one thought each), `pos`, `size` |
| `text_dense` | simple | `text`, optional `kicker`, `top`, `height`, `max`, `min`. Font size shrinks to fit the box (floor `min`, default 36). Below the floor the text stays and overflows visibly: split it instead. |
| `problem_list` | standard | `lines`, `items` (red X rows), optional `footer` |
| `step_cards` | standard | `lines`, `cards` of `label`, `sub`, `icons` |
| `stat_card` | designed | `lines`, `card_title`, `rows` of `label`, `value` 0 to 1, `color`, optional `text` |
| `chat_card` | designed | `lines`, `greeting`, `prompt`, optional `reply` |
| `inbox_card` | designed | `lines`, `rows` of `name`, `msg`, `status`, `state` (good, warn, bad) |

Icons are keys into `glyphs/` (real brand marks: tradingview, tiktok, shopify, amazon, stripe, youtube, instagram, calendly, caldotcom, whop, fanbasis). Add a real mark to extend it. A missing key stops the build; never draw a lookalike.

## Brand tokens

`brands/*.json`: `font` (helvetica, arial, segoe, georgia, impact), `colors` (bg, ink, card, mute, silver, accent, accent_hi, accent_lo, good), `emphasis` (underline on/off + color, box on/off, gradient on/off + stops), `type` (weight, tracking), `logo` (path, placement none | first), `glow`. See `brands/pulsify.json` and `brands/sample-client-blue.json`.

## Not covered yet

- Type behind the subject (needs a clean cutout matte of the person). The Pulsify slide 1 treatment is still hand-built from `output/highlight-saas/claude-v2/slide1_mockups8.py`.
- Charts from real data (the `stat_card` bars are percentages the spec supplies, not a chart engine).
- Fonts are limited to ones installed on this PC. A production render service needs fonts that are licensed and installed there.
- The renderer here is local headless Chrome. The app runs on Cloudflare, so production rendering needs a render service chosen and verified (see the ticket for layer 3).
- Blurred-card and cutout drop shadows beyond the plain card shadow.
- The 13 approved Pulsify slides were built with earlier scripts and are not regenerated byte for byte by this engine. It reproduces the same slide types and look.
